轻量中文个人待办应用。用浏览器记录任务、完成打勾；数据仅保存在当前浏览器，不需要账号。

## 第一版功能

- 添加任务，支持 Enter 提交和中文输入法，最多 200 个字符。
- 标记完成或恢复未完成，按全部、未完成、已完成筛选。
- 删除任务，撤销最近一次删除。
- 自动本地保存，显示完成进度；保存失败时给出提示。
- 适配手机和桌面，支持键盘操作和屏幕阅读器。

## 本地运行

需要 Node.js 18 或以上，不需要安装第三方依赖。

```powershell
cd D:\SunJX\projects\todo
npm run dev
```

打开 http://127.0.0.1:4175 。使用 `npm run check` 检查 JavaScript 语法。

## 文件

- `dist/index.html`：页面结构、标题和图标。
- `dist/styles.css`：样式和响应式布局。
- `dist/app.js`：任务状态、交互和浏览器存储。
- `server.mjs`：仅监听本机的开发服务器。
- `.openai/hosting.json`：Sites 静态托管配置。

`dist/` 为直接编写的源文件，保留在版本控制中，无需构建。浏览器存储键为 `sunjx.todo.v1`。不同浏览器、设备和站点地址的任务不互通；清除站点数据会清空任务。第一版不含账号、云同步、提醒和多人协作。

若读取到损坏的存储，页面不会覆盖原数据，本次会话停止自动保存并显示提示。普通写入失败时保留页面状态，后续操作会重新尝试保存。

支持 `document.modelContext` 的浏览器可使用 `list_todos`、`add_todo` 和 `set_todo_completed`，与页面共享同一任务状态；不支持时仍可正常使用页面。
