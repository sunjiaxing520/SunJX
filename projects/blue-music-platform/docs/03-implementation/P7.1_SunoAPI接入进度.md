## 本次目标

依据 `https://docs.sunoapi.org` 增加一个可热切换的 `sunoapi_org` 音乐 Provider。
正式部署预设 HTTPS 回调公网地址后，超级管理员只需在音乐创作页填写 Token、
选择实现和模型即可使用；Token 只以密文保存，不返回明文。

`sunoapi.org` 是第三方服务，不等同于 `platform.suno.com` 官方 API。现有
`official` 和 `compatibility` 实现继续保留。

  - `GET /api/v1/generate/record-info` 查询任务并映射结果；

  - 对歌词、标题和风格长度做模型级前置校验。
- 新增异步等待状态：提交拿到外部 `taskId` 后立即持久化并释放 worker，回调是
  主唤醒路径，30 秒状态查询是回调丢失时的兜底；等待状态不消耗失败重试次数。
- 新增公开回调入口：
  `POST /api/v1/music/callbacks/sunoapi-org/{task_id}/{signature}`。
  每个任务使用后端随机密钥计算独立 HMAC 地址；Token 不放进回调 URL。
  这是本系统生成的访问凭证，不是供应商对通知正文的数字签名。回调只作为查询提示，
  最终成功或失败必须由带 Token 的详情接口确认；不信任回调携带的下载地址。
- 回调只快速校验、落库和唤醒任务，音频下载继续由 music worker 完成，避免超过
  供应商要求的 15 秒响应时间。`text`、`first`、`complete`、`error` 阶段均持久化。
- `music_provider_settings` 已增加实现选择、加密 Token、Token 提示、回调公网地址
  和内部回调密钥；音乐任务增加提交及回调时间字段。
- 前端音乐页已增加“接口设置”弹窗，可选择实现、模型、填写或替换 Token、配置
  HTTPS 回调公网地址；接口状态和任务详情可显示第三方实现及回调进度。

## 本次补齐的运行约束

- 数据库条件更新抢占任务，重复队列消息不会重复执行；回调不把正在执行的任务改回待处理。
- 使用设置行锁串行判断 SunoAPI 在途任务数量，等待供应商生成期间继续占用并发名额。
  Redis 保留原有请求频率限制；默认每 30 秒补查，等待不增加失败重试次数。
- POST 读写中断、5xx、无法解析响应或缺少 taskId：报 `SUNOAPI_SUBMISSION_UNKNOWN`，
  停止自动提交，也不允许直接点击重试重发。先核对供应商后台；后续回调带回编号可恢复查询。
  已有外部编号的重试只查详情。连接建立前的失败、明确限频响应仍采用有上限的延迟重试。
- `text/first/complete/error` 乱序或重复通知不会回退阶段；完成通知早于可下载结果时仍有最小
  等待间隔，避免紧密循环。error 通知同样唤醒详情查询，不直接宣布业务失败。
- 达到生成等待期限后暂停为失败，保留编号供手动重查。worker 中断且没有拿到编号时停止重发；
  已有编号时恢复入队。worker 每 30 秒扫描中断和到期任务，不依赖用户刷新页面。
- 创建任务时加密保存 Token 快照，后台更换 Token 或实现只影响新任务。旧任务使用原凭证；
  原凭证被供应商吊销时旧任务仍会报鉴权失败，不会擅自换到另一个客户账号。
- 清除 Token 后禁止新任务，并屏蔽环境变量 Token 后备；不删除旧任务的加密凭证快照。
  旧任务和业务库备份仍须按凭证数据保管。更换 Token 清理旧的额度缓存，避免显示另一账号余额。
- 当前只开放完整生成与结果回调；第三方实现下续写/改编在扣内部额度前拒绝，页面隐藏相应操作。
- 应用日志和 Uvicorn 访问日志隐藏回调 URL 中的凭证。正式反向代理的访问日志同样要隐藏该段，
  不把完整回调 URL 交给普通成员。回调必须配置公网 HTTPS 站点根地址，不附加 /api 路径。
