# 蓝乐公网临时体验维护说明

更新时间：2026-08-24

## 用途

本方案用于让异地客户临时体验开发机上的蓝乐项目。它使用 Cloudflare Quick
Tunnel 生成随机 `https://*.trycloudflare.com` 地址，适合演示和测试，不作为
正式生产部署。

公网调用链：

```text
异地浏览器
  -> Cloudflare HTTPS 临时网址
  -> cloudflared 出站加密隧道
  -> 127.0.0.1:4173 前端生产预览
  -> /api 同源代理
  -> 127.0.0.1:8000 FastAPI
```

PostgreSQL `5432`、Redis `6379`、FastAPI `8000` 和 Suno 兼容服务 `3000` 不
建立公网入口。浏览器只访问一个 HTTPS 来源，前端默认使用相对地址 `/api/v1`。

## 运行位置

```text
cloudflared：D:\DevTools\Cloudflared\cloudflared.exe
启动脚本：D:\SunJX\projects\blue-music-platform\scripts\start-public-preview.ps1
运行日志：D:\DevTools\Logs\BlueMusic\
最新地址：D:\DevTools\Logs\BlueMusic\public-url.txt
```

## 启动

先确认 Docker、PostgreSQL、Redis、FastAPI 和 music worker 已运行，然后执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File `
  D:\SunJX\projects\blue-music-platform\scripts\start-public-preview.ps1
```

脚本会执行前端生产构建、启动 `vite preview`、重启本项目的 Quick Tunnel，并
输出公网地址。每次隧道进程或电脑重启后，地址通常会变化。

## 安全边界

- 必须保留蓝乐登录认证，不得创建免登录公网入口。
- 不建立路由器端口映射，也不开放数据库、Redis、FastAPI 或 Suno 端口。
- 不在日志、文档或公网响应中输出密码、Cookie、API Key 或内部 Token。
- 临时演示结束后停止 `cloudflared.exe` 和 `vite preview` 进程。
- 当前开发测试密钥不得作为客户正式上线密钥。
- Quick Tunnel 没有固定域名和可用性承诺，不适合正式交付。

## 正式部署方向

客户需要稳定网址时，改为域名绑定的 Cloudflare Named Tunnel 或云服务器部署，
并增加 HTTPS、固定域名、生产密钥、备份、监控、访问控制和服务自启动。前端
继续使用同源 `/api/v1`，业务代码不需要切换到某台机器的 IP 地址。
