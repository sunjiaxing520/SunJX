# 音频下载与代理兼容

## 故障与修复

2026-10-15，本机 iKuuuVPN 将供应商音频域名解析到198.18.0.0/15虚拟地址。
歌曲生成成功，但蓝乐公网地址校验阻止归档，页面退回供应商地址试听。

新增 `MUSIC_DOWNLOAD_DOH_FALLBACK`，默认关闭，本机 `.env` 已开启。
仅当域名解析出现该 Fake-IP 网段时，下载器通过固定的 Cloudflare DNS-over-HTTPS
查询 A 记录，检查所有返回地址均为公网地址，并固定连接到验证后的地址。
Host、TLS SNI及证书校验保留原域名；每次重定向重新检查。
普通公网解析走原流程。内网、回环、链路本地、直接填写的虚拟IP及不可信DNS结果仍拒绝。
没有关闭VPN、改系统DNS、硬编码CDN地址或放宽私网下载限制。

该配置不绑定VPN品牌或节点，应用重启后自动读取。换VPN后如果使用不同的虚拟网段，
或无法连接DNS服务，下载仍可能失败，不能声称兼容任何网络。失败保留结果记录及归档错误。
