# SunJX 个人作品集 Demo

Apple 风格的静态个人主页：个人介绍、作品封面、作品说明、跳转入口、关于和联系弹窗。包含三个虚构作品的概念配图和独立示例页面，不代表真实上线产品。姓名、介绍与联系方式均待替换确认。

## 本地预览

在本目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765 。也可直接双击 `index.html`，不需要安装依赖或构建。

## 替换真实作品

编辑 `projects.js` 的数组：`name` 为作品名称，`description` 为简介，`tags` 为标签，`image` 为图片路径，`url` 为实际作品地址。图片建议使用 WebP / PNG / JPG，主推封面约 2.45:1，普通封面约 1.57:1。首项自动作为主推作品。所有作品入口均在新标签页打开。

编辑 `index.html` 修改个人介绍与关于文字；将联系按钮改为真实邮箱链接，或在联系弹窗填入自己的社交信息。

## 部署自己的服务器

将本目录中的 HTML、CSS、JS 和 `assets/` 上传到 Nginx / Caddy 的站点目录即可。无需 Node.js、数据库或服务器端代码。此 demo 未部署到生产服务器。

所有 SVG 封面由本 demo 自制，无远程字体、图片、分析脚本或第三方请求。支持手机布局、键盘操作和减少动态效果偏好。
